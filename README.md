# F1 Race Result Website

## Overview
A simple website that uses OpenF1 and Flask to display the results of races.

**Features:**
* **Dropdown Selection: Easy selection of races and years.**
* **Extra Information: Includes time between drivers and drivers championship points earned.**
* **Text-Based Version: The commented out code includes a text-based terminal display, using the Tabulate and Rich libraries to show a visually appealing table.**

## Why I Built This
I created this project to teach myself Flask as wel as how to work with API's.

## How to Run Locally
1. Clone or fork this repository:
   ```bash
   git clone https://github.com/aaravmhaisalkar/State-Game-Project
   ```
2. Install flask:
   ```bash
   pip install flask, requests, tabulate, rich
   ```
3. Navigate to the project folder and run the app:
   ```bash
   python3 "flaskTesting.py"
   ```
4. Open `http://127.0.0.1:5000/`
